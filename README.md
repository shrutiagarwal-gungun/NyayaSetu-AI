# ⚖️ NyayaSetu AI

### AI-Powered Indian Legal Assistant using Retrieval-Augmented Generation (RAG)

NyayaSetu AI is an AI-powered legal assistant that uses Retrieval-Augmented Generation (RAG) to answer questions from Indian legal documents and assist users in understanding uploaded legal documents.

## 🚀 Live Demo

[Try NyayaSetu AI](https://nyayasetu-ai-f2mnat3jss3u4zid2cqff4.streamlit.app)

## ✨ Features

- RAG-based Indian legal question answering
- Curated Indian legal document knowledge base
- Legal PDF upload and analysis
- Conversational follow-up questions
- Source and page-based citations
- AI-assisted legal document understanding
- Simplified explanations of legal information

## 🛠️ Tech Stack

- Python
- Streamlit
- LangChain
- ChromaDB
- Sentence Transformers
- Groq LLM
- PyMuPDF

## 📚 Knowledge Base

- Constitution of India
- RTI Act, 2005
- Consumer Protection Act, 2019
- Digital Personal Data Protection Act, 2023
